# OVA — Modelo OSI | Redes de Computadores
### Universidad de Córdoba · Licenciatura en Informática

Objeto Virtual de Aprendizaje (OVA) interactivo y multimedia diseñado para la enseñanza y apropiación de las 7 capas del **Modelo de Referencia OSI (ISO/IEC 7498-1)** en cursos de Redes de Computadores.

![Universidad de Córdoba](assets/unicor.svg)

---

## 📖 Características del Recurso

1. **🔍 Fundamentación Conceptual:**
   - Origen histórico del modelo OSI (ISO, 1984).
   - Justificación, ventajas y principios de comunicación entre pares (*peer-to-peer*).
   - Comparativa de referencia con el modelo TCP/IP.

2. **🗂️ Pila Visual de las 7 Capas (OSI Stack):**
   - Representación gráfica de las 7 capas con sus PDU oficiales (Mensaje, Datos, Segmento, Paquete, Trama y Bit).
   - Mnemotecnias en español e inglés para memorización rápida.

3. **📚 Explorador en Detalle por Capas:**
   - Panel interactivo de pestañas con función principal de cada capa.
   - Catálogo de protocolos representativos clasificados por capa.
   - Dispositivos de red clave (Switches, Routers, Hubs, Firewalls, etc.).
   - Ejemplos paso a paso de transmisiones reales (HTTP/TLS, TCP/UDP, enrutamiento IP, direccionamiento MAC, pulsos en fibra y cobre).

4. **🔄 Animación del Flujo de Datos:**
   - Demostración dinámica de **encapsulación** en el emisor (7 ➔ 1) y **desencapsulación** en el receptor (1 ➔ 7).
   - Simulación secuencial del envío de un correo electrónico con SMTP y TLS.

5. **🎮 Minijuego Educativo "Desafío OSI":**
   - **Modo 1: El Viaje del Paquete:** Ensamblaje visual interactivo de cabeceras en tiempo real.
   - **Modo 2: Detective OSI:** Resolución de 6 casos prácticos de soporte técnico y diagnóstico de fallas de red (*troubleshooting*).
   - **Modo 3: Caza-Protocolos (Arcade 30s):** Clasificación contrarreloj de dispositivos y protocolos con racha de combo.
   - **Efectos sonoros sintetizados** mediante Web Audio API (100% autónomo, sin dependencias externas).

6. **✍️ Autoevaluación Formativa:**
   - Banco de preguntas de selección múltiple con retroalimentación explicativa inmediata y cálculo de porcentaje de acierto.
